### 代码层（`app.asar` 307,867,744 字节，关键字节偏移为 3.12.3 样本值）

- 上传链路完整：`/api/v1/snapshot/upload-credential`（@252878222 等 7 处）→ `RepoSnapshotUploadClient` → OSS `PUT`/multipart `POST repo-snapshot.tar.gz.enc`（@253321856）→ 凭证响应需含 `oss.x_oss_security_token`、`encryption.public_key`、`callback.*`、`max_size`（@253317526）。
- **`.git` 强制收录**：`appendRootGitMetadataPaths` 把工作区根 `.git` 全部内容递归加入候选（@253284985）；过滤器 `R5`/`F_e` 对 `.git` 段路径无条件放行并绕过二进制检查（@253281114、@253283145）；降级遍历 `walkFiles` 则跳过一切名为 `.git` 的目录（`Mct=new Set([".git"])`）。
- **排除规则**（反而存在）：`.env*`、`.npmrc`、`id_rsa/id_dsa/id_ecdsa/id_ed25519`、`*.pem/*.key/*.p12/*.pfx`、路径含 token/secret、>1MB 大文件（`bct` 集合 + `looksLikeSecretPath`，@253281114）。
- 机制延续性：`migrateLegacyRepoSnapshotRootDir`（repo-snapshots → checkpoints 迁移，@253277838）说明并非 3.12.3 新增。
- 门控：host 侧 `Cf(e)` 要求 `repoSnapshotIndexingEnabled===true && repoSnapshotIndexingUserConfigured===true`（@293298714）→ **"开关完全无效"的指控在这版 Windows 代码里未获支持**。
- 制品内容：`<snapshotId>/meta/prompt.json`（**会话 prompt 文本**）+ `meta/manifest.json` + `extra-meta/*` + 变更文件。
